# StudentAI

A modern AI-powered learning assistant built with React and Vite to help students excel in their academic journey.

## 🎯 Overview

StudentAI is an intelligent educational platform designed to provide personalized learning experiences. Whether you're struggling with complex concepts, need help with assignments, or want to optimize your study habits, StudentAI is here to support your academic success.

## ✨ Key Features

- **AI-Powered Tutoring**: Get instant help with homework, explanations, and learning concepts
- **Personalized Learning Paths**: Adaptive curriculum based on your learning style and progress
- **Study Materials**: Access to comprehensive study guides, notes, and resources
- **Assignment Assistance**: Get step-by-step guidance without spoiling answers
- **Progress Tracking**: Monitor your improvement over time with detailed analytics
- **Real-time Chat**: Interactive conversations with AI for immediate doubt clarification

## 🛠️ Tech Stack

- **Frontend**: React 18+ with Vite for lightning-fast development
- **Build Tool**: Vite - Next generation frontend tooling
- **Styling**: CSS for responsive and modern UI
- **Backend**: Node.js with PLpgSQL (PostgreSQL)
- **Database**: PostgreSQL for secure data management

### Project Composition
- JavaScript: 90.6%
- CSS: 5.8%
- PLpgSQL: 2.6%
- HTML: 1%

## 📦 Getting Started

### Prerequisites
- Node.js (v16 or higher)
- npm or yarn package manager

### Installation

1. Clone the repository:
```bash
git clone https://github.com/8688-harshu/studentAI.git
cd studentAI
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm run dev
```

The application will open at `http://localhost:5173` with HMR (Hot Module Replacement) enabled.

## 🚀 Build & Deployment

### Development Build
```bash
npm run dev
```

### Production Build
```bash
npm run build
```

### Preview Production Build
```bash

```
